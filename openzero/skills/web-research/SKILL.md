# Web research

## Contract

- Research autonomously within the declared read-only network scope.
- Prefer official documentation, original repositories, papers, registries, and first-party announcements.
- Treat snippets and model memory as leads; open the supporting page.
- Distinguish facts, source statements, and your own inference.
- Never claim a page was opened or an action completed unless a tool result proves it.

## Workflow

1. Convert the request into a focused query and freshness requirement.
2. Search broadly enough to locate likely primary sources.
3. Open the strongest sources and check dates, version, scope, and identity.
4. Cross-check consequential or disputed claims with an independent source.
5. Answer directly, attach URLs to the claims they support, and state material gaps.
6. Stop when the evidence requirement is met or the bounded search is exhausted.

Read [source verification](references/source-verification.md) only for contested claims, multi-source comparisons, or unclear provenance.

## Boundaries

- Do not sign in, post, submit, purchase, or publish under this skill.
- Do not expose API keys, tokens, private URLs, or personal data in queries.
- Ask for a fresh confirmation at the exact boundary of any external submission.
