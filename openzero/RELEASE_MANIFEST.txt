OPENZERO RELEASE
Version: 7.3.0
Channel: stable
Release date: 2026-09-30

Highlights:
- Independent local nodes; no required owner main node or company database.
- Local default mode, blank remote Hive address, explicit sharing.
- Optional direct peer notes with separate peer keys and review inbox.
- Runtime and installers distributed through GitHub release assets and checksums.
- Tab Pilot 0.3.1 verified ZIP preparation with explicit browser approval.
- Existing source improvement, rollback and adapter-training workbenches preserved.
- Local inference stays local; peer notes do not distribute inference or training.
