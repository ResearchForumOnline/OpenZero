Your machine · Your models · Independent nodes

An AI workspace you can keep.

Chat, code, research and run bounded automation on your own Linux machine or server. OpenZero combines local model routing, a browser workspace and durable tools without a required main node, company login or TalkToAI backend.

Local models

Ollama, a Ministral 8B runtime-template default, Gemma compatibility fallback, CPU profiles and your own model selection.

Durable work

File and tool workflows with checkpoints, budgets, visible status, stop/revoke and reviewed consequential actions.

Browser access

Optional Tab Pilot connects a tab you explicitly grant to your own node. Inspect, click, type and navigate with visible controls.

Improvement workbench

Source candidates, diffs, recorded checks, reviewed apply and rollback. Optional local adapter training stays separate from inference.

Direct peer notes

Opt-in, operator-selected peers exchange selected notes into a review inbox. No required coordinator or automatic private-chat sharing.

Private operation

Loopback defaults, local knowledge, hashed API keys, optional voice and an offline bundle path for prepared machines.

Review, verify, install

On a Linux machine you administer, verify the installer checksum and review the script before running. The runtime ZIP is separately verified before extraction.

curl -fL https://github.com/ResearchForumOnline/OpenZero/releases/download/v7.3.0/install.sh -o install.sh
curl -fL https://github.com/ResearchForumOnline/OpenZero/releases/download/v7.3.0/install.sh.sha256 -o install.sh.sha256
sha256sum -c install.sh.sha256
less install.sh
bash install.sh --desktop

Use --server --no-tab-pilot for a headless node, or --skip-model to avoid the default model download. Open your installed panel at http://localhost:1024.

GitHub hosts release files; it does not coordinate local inference. Dependencies and models need downloads during online setup. Prepare an offline bundle for disconnected operation. Optional cloud APIs, web search and remote peers need the services you choose.

Approval-gated local tools

Operator policy and local audit control tool access; automatic privilege escalation is blocked in production. Source self-editing and other writable state remain high risk and require review.

Tools and research, preserved in source

Find the improvement workspace, local API, Tab Pilot source and research archive on GitHub. Archived ZeroMint ISO parts and checksums are documented in the preservation guide.
