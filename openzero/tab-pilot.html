OpenZero Tab Pilot / 0.3.1

One granted tab. Your own AI node.

Tab Pilot lets your self-hosted OpenZero runtime inspect and operate a browser tab you explicitly grant. Navigation, clicking, typing, selection, scrolling and history are bounded by local policy and visible stop controls.

Connect locally

  1. Download the ZIP and its checksum; verify with sha256sum -c OpenZero-Tab-Pilot-v0.3.1.zip.sha256.
  2. Extract it. Open your Chromium browser's extension settings, enable Developer mode and choose Load unpacked.
  3. Select the extracted folder. Generate a scoped Tab Pilot token in your local OpenZero panel.
  4. Enter the token and http://127.0.0.1:1024 in extension Options. For a remote node, use your own SSH tunnel.
  5. Grant one ordinary web tab and describe a task. Stop and revoke access whenever you wish.

Linux and Windows setup helpers prepare the same verified package. They do not bypass browser approval or require an owner-hosted CRX updater.

Visible, bounded browser work

The verified OpenZero runtime plans one schema-checked action at a time. New origins, consequential actions and personal-data entry pause for review. Password/payment fields, CAPTCHAs, file uploads, privileged browser pages and arbitrary JavaScript are blocked. Tab authority is not retained after a full browser restart.

The Chrome Web Store listing is a separate public distribution channel. Its published version may differ from this GitHub release. Existing administrator-managed installs need local policy review before migration.

Install OpenZero first

Use the checksum-verified installation guide. No company account, main node or shared trial is required. Models must be installed on your own node before planning works.
